# L0–L4 总报告素材索引

本文件用于以后把 L0、L1、L2、L3、L4 五份阶段报告汇总成一份完整项目报告。通俗地说，它是一张“素材地图”：先告诉总报告应去哪里找结论，再指出结论对应哪张图、哪个指标文件和哪份原始记录。图片用于直观看现象，CSV/JSON 用于核对数值，`states.csv` 与 `run.json` 用于追溯一次仿真实际做了什么。

专业上，建议把每项成果按以下证据层级引用：

1. 阶段主报告负责给出任务背景、方法、结果和适用边界；
2. 报告内嵌图片负责展示轨迹、误差、姿态、力或最终画面；
3. `metrics.csv`、`metrics.json`、`acceptance.json` 或汇总 CSV/JSON 负责保存指标定义和机器可读数值；
4. 独立实验目录中的 `config.json`、`run.json` 和 `states.csv` 负责保存实际配置、运行清单与原始时序数据。

以下路径全部从项目根目录 `Rbt-Project-Mid/` 开始。L0–L4 的成果仍分别保存在 `Pro2/output/L0/` 至 `Pro2/output/L4/`，本索引只建立引用关系，不复制或改写实验数据。

### 2.3 补充调参的引用方法

L0-E5 是 2026-11-03 补做的凸 MPC 输入代价总系数 `u_weight` 三点实验。三份配置位于 `Pro2/experiments/L0/mpc_input_weight/`，唯一修改字段为 `u_weight=1e-7/1e-6/1e-5`。三次运行均完成 12 s 仿真，具有 12,000 个物理步和 1,200 个日志样本，MPC/WBC QP 失败样本均为 0。

可以写入：在这三个候选值以及当前平地、$0.2\ \mathrm{m/s}$、无扰动直行场景中，`u_weight=1e-5` 的速度 RMSE、最大倾角和高度波动最小，因此作为当前场景推荐值；相对默认 `1e-6`，其速度 RMSE 降低 14.39%、最大倾角降低 11.79%，力矩平方积分增加 2.83%。

必须保留的边界：这里只比较三个候选值，不能写成全局最优。`metrics.json` 中的综合分数使用实验前人为设定的汇总权重，即速度 RMSE 40%、最大倾角 20%、高度标准差 15%、力矩平方积分 20%、MPC 求解 P95 5%；它只帮助汇总多个指标，不能证明客观最优性。L0 调的是输入代价总系数 `u_weight`，L2 `mpc_vx_weight` 调的是状态权重 `state_weights[9]`，两者不能混称同一个实验。

### 5.3 可直接写入总报告的结论与边界

可以写入：LQR、iLQR 和当前 Convex MPC 都可放进有限时域最优控制框架理解；MPC 的关键是在线滚动求解与只执行第一步，当前 OpenLoong 实现通过线性化单刚体模型、二次代价和显式接触/摩擦约束得到凸 QP。足式机器人因接触切换、单边接触、摩擦约束、姿态与落脚几何变化以及输入饱和，不能仅靠一个固定 LQR 增益覆盖全部行走过程。NMPC 可以保留更多非线性，但通常付出更高计算成本和更复杂的收敛问题。

必须保留的边界：L3 本身没有运行 LQR 或 iLQR 实验，也不能用 L2 权重、时域和扰动实验直接证明 MPC 一定优于 LQR。L2 的步高实验反映全身任务负担，不是算法类别对比。Convex MPC 与 NMPC 的实际仿真对照应引用 L4 第四项。
