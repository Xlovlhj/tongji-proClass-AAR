# 侧向外力扰动对照实验分析

> 本文由 `Pro2/tools/analyze_l2_results.py` 从各运行目录的 `run.json` 和 `states.csv` 生成。数值结果保存在同目录的 `metrics.csv`。

## 1. 改了什么

本组唯一自变量是 `push_force_y`，单位为 `N`。实验配置路径为：

- `Pro2/experiments/L2/lateral_push/no_push.json`
- `Pro2/experiments/L2/lateral_push/push_50N.json`
- `Pro2/experiments/L2/lateral_push/push_100N.json`

各条件的实际取值读取自 `run.json`，具体来源记录在 `metrics.csv` 的 `variable_value_source` 列。

**单变量配置检查通过：**在运动、仿真和控制相关字段中，三次运行只改变了本组指定的自变量。

## 2. 观察到什么

统一分析窗口为 `5.0 s` 至日志末尾。`最大 Roll/Pitch 分量` 定义为该窗口内 `max(max|Roll|, max|Pitch|)`。

| 条件 | 自变量 | 运行/数据/验收校验 | 分析样本 | 内部参考 vx RMSE (m/s) | 最大 Roll/Pitch 分量 (rad) | 高度标准差 (m) | 力矩平方积分 (N²·m²·s) | MPC qpOASES QP CPU time P95 (ms) | MPC+WBC 非零状态样本数 | 恢复时间原始值 (s) |
|---|---:|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 无扰动 0 N | 0 | completed / ok / ok | 700 | 0.02354 | 0.03739 | 0.004629 | 1.192e+05 | 0.4841 | 0 | — |
| 侧推 50 N | 50 | completed / ok / ok | 700 | 0.02371 | 0.03723 | 0.004649 | 1.196e+05 | 0.475 | 0 | — |
| 侧推 100 N | 100 | completed / ok / ok | 700 | 0.02439 | 0.03381 | 0.004758 | 1.222e+05 | 0.4749 | 0 | — |

`no_push` 是**自然步态参照**：它保留相同的行走命令和时间窗，但不施加外力，用于识别正常步态本身的周期起伏。
扰动峰值使用从施力开始起固定 2.0 s 的瞬态观察窗，即 `[push_at, min(push_at + 2.0 s, 日志末尾)]`；该窗口包含 0.1 s 的施力阶段。
恢复计时从施力结束 `push_at + push_duration` 开始。每个连续样本必须同时满足：机身坐标系 `vx`、`vy` 相对控制器内部速度参考的误差均不超过 `0.05 m/s`，Roll、Pitch 相对施力前 1.0 s 均值的偏差均不超过 `0.03 rad`，并连续保持至少 `0.5 s`。若相邻记录间隔大于 `max(0.05 s, 2.5×中位采样间隔)`，连续计时会重置。

**恢复判据适用性结论：**`no_push` 自然步态参照本身也未连续满足上述固定阈值。这说明正常周期步态的速度或姿态起伏已经超出该阈值。周期步态下该固定阈值判据无效，无法给出有效恢复时间，也不能据此判断 50 N/100 N 组是否恢复。下表仍保留 `recovered_in_window` 与 `recovery_time_s` 的原始计算结果供审计。

下面的原始峰值以每次运行自身的施力前 1 s 均值为基准。它们用于查看单次响应，不用于计算相对 `no_push` 的扰动增量。

相对自然步态的扰动增量采用**同时间样本差分**：只在 `7.00–9.00 s` 比较，要求两次运行的时间戳逐点相等（容差 `1e-6 s`），不插值、不做最近邻匹配。每个状态先计算 `push(t)-no_push(t)`，再统计最大绝对差；额外高度下降定义为 `max(0, max(no_push_z(t)-push_z(t)))`。

| 条件 | 对齐样本 | max|ΔRoll| (rad) | max|ΔPitch| (rad) | max|Δvx| (m/s) | max|Δvy| (m/s) | 相对 no_push 最大额外高度下降 (m) |

按上述时间对齐定义，本批侧推相对自然步态参照的差分结果为：
- **侧推 50 N**：max|ΔRoll| 0.01809 rad，max|ΔPitch| 0.004706 rad，max|Δvx| 0.0303 m/s，max|Δvy| 0.08821 m/s，额外高度下降 0.004901 m。
- **侧推 100 N**：max|ΔRoll| 0.03578 rad，max|ΔPitch| 0.008811 rad，max|Δvx| 0.05764 m/s，max|Δvy| 0.1829 m/s，额外高度下降 0.01071 m。

- 相对基线，**侧推 50 N** 的内部参考速度 RMSE 增加 0.7%，最大 Roll/Pitch 分量 降低 0.4%，力矩平方积分 增加 0.4%。
- 相对基线，**侧推 100 N** 的内部参考速度 RMSE 增加 3.6%，最大 Roll/Pitch 分量 降低 9.6%，力矩平方积分 增加 2.5%。

## 3. 为什么可能出现这些变化

侧向外力先改变基座横向速度和姿态，MPC 通过允许的接触 wrench 修正，WBC 再把期望广义力映射到全身关节。恢复能力同时受摩擦、足底力矩约束、支撑切换和关节力矩限幅影响，不能仅由某一个峰值解释。

这段解释给出与控制结构一致的机制假设。因果判断以本组单变量配置有效、运行完成且重复实验趋势一致为前提。

## 4. 结论边界

- 所有常规对比指标统一使用 `5.0 s` 至日志末尾的数据；扰动恢复姿态基准使用施力前 1.0 s。
- `controller:left_force_z_est_N` 与 `controller:right_force_z_est_N` 是动力学反算值，不是 PhysX 接触传感器实测值。
- 力矩平方积分是控制努力代理量；绝对机械功也是机械侧代理量，二者都不是电机电能。
- `controller:mpc_solve_s` 与 `controller:wbc_solve_s` 是 qpOASES 报告的 QP CPU time，由本实验 CSV 以 100 Hz 抽样记录；它们不包含预测矩阵构造、QP 组装，也不等于完整控制循环耗时。
- `MPC+WBC 非零状态样本数` 是统一分析窗口内两个求解器状态字段非零样本数之和，不等于互不重复的时间点数。
- 当前结果来自 Isaac Sim/PhysX 中的一次确定配置运行。没有重复试验时，只能说明本次仿真的差异。
