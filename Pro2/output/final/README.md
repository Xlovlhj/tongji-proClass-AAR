## 更新第一页视频

从项目根目录执行：

```text
python3 Pro2/output/final/update_cover_video.py
python3 Pro2/output/final/verify_presentation.py --export-pdf --render
```

第一条命令只替换当前PPT第一页的视频、封面静帧及仍存在的时长说明，并从 `assets/video_sources.json` 读取实际时长，更新第一页备注与外部来源记录。用户已删除的封面说明不恢复；第2–15页以及对应详细讲稿逐字节保留。第二条更新同版PDF和预览，不运行仿真。输入PPT快照与逐项保留校验记录见 `checks/cover_video_update.json`。

需要重新剪辑现有录像时，先运行下列命令，再执行上面的更新步骤：

```text
python3 Pro2/output/final/build_demo_video.py
```

`build_presentation.py` 不带参数会从原生成脚本重新创建全部15页，覆盖编辑软件中后续保存的修改。更新视频使用上面的 `update_cover_video.py`；`build_presentation.py --update-cover-only` 也会转入同一更新器。
