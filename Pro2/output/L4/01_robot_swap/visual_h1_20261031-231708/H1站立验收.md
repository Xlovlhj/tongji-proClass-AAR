# L4 模型更换：H1-2 站立实验

## 先看结论

- Isaac 实验是否完成：**是**。
- 8 秒 FixStand 验收：**通过**。
- 实际控制方式：**Unitree H1-2 FixStand 关节位置 PD + 骨盆姿态/位置踝关节反馈**。
- OpenLoong MPC/WBC 是否控制本实验：**否**。

这个实验真实加载并运行了另一台人形机器人，用于验收模型资产、关节、接触和 Isaac 物理初始化。它没有把 AzureLoong 的 31 关节控制力矩直接套到 H1 的 27 关节上，因此不能作为“OpenLoong 已完成 H1 移植”的证据。

## 实验设置

- 机器人：Unitree H1-2 Handless
- 仿真时长：8.000 s
- 实际姿态插值时间：3.000 s
- 初始化方式：从零位插值到 FixStand 最终姿态
- 最终姿态保持时间：5.000 s
- 物理步长：0.002000 s
- 初始骨盆高度：1.0310 m
- 关节数：27
- 物理后端：PhysX CPU
- 控制目标：本机 H1-2 `FixStand` 的 27 关节目标姿态
- 参数来源：`/home/xqw/xqw-file/unitree_rl_lab/deploy/robots/h1_2/config/config.yaml` 的 `FSM.FixStand`
- 源配置姿态插值区间：[0.0, 3.0] s
- PD 增益倍率：Kp × 1，Kd × 1
- 平衡反馈：Pitch (1.5, 0.1)，Roll (1.2, 0.15)，修正限幅 ±0.75 rad
- 基座位置反馈：X (2, 1)，Y (0, 0)

## 验收指标

| 指标 | 数值 | 判据 |
|---|---:|---:|
| 完成仿真时间 | 8.000 s | ≥ 8.000 s |
| 最低骨盆高度 | 0.989278 m | ≥ 0.85 m |
| 最大 Roll/Pitch | 0.077643 rad | ≤ 0.20 rad |
| 最大水平漂移 | 0.060733 m | ≤ 0.10 m |
| 最终关节目标 RMSE | 0.036503 rad | ≤ 0.10 rad |
| 最大关节速度 | 8.751992 rad/s | 记录项 |
| 最大 PD 力矩估计 | 48.383448 N·m | 记录项 |
| 最大显式 actuation 缓冲 | 0.000000 N·m | 记录项 |
| 最大投影关节力矩 | 48.123581 N·m | 记录项 |
| 最大踝关节平衡修正 | 0.215653 rad | ≤ 0.750 rad |

`explicit actuation` 是通过 `set_dof_efforts()` 写入的显式力矩缓冲；本实验使用隐式 PD drive，因此它应为零。`projected joint force` 是 PhysX 将连杆传入关节的作用力投影到转动自由度后的量，更适合观察本实验中的关节受力。平衡反馈只修正左右踝的姿态目标；表中的 27 关节 FixStand 名义姿态和每关节 Kp/Kd 仍直接来自上述配置文件。

## 文件

- `config.json`：实际运行参数；
- `states.csv`：基座、关节位置、速度、PD 力矩估计和 PhysX 投影关节力矩；
- `metrics.json`：验收指标；
- `run.json`：Isaac、资产和控制来源；
- `scene.usda`：本次组合后的场景。

## 与 OpenLoong 的边界

当前 OpenLoong 桥接器仍固定 31 关节和 `nv=37`，H1-2 是 27 关节和 `nv=33`。因此本实验只证明 H1-2 可以在 Isaac 中完成独立的物理站立验收。MPC/WBC 的 H1 移植仍需 H1 URDF、动力学参数、WBC 任务重建和控制桥维数参数化，详见同层目录的 `preflight/h1_2_handless_preflight.md`。
