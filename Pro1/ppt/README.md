# raa-v0 汇报 PPT

打开 `raa-v0.pptx` 即可修改。按 `Pro1/6546682.pdf` 调整为 10 页、16:9，封面填写肖淇文、2453703 和 2026 年 10 月 13 日。内容包括系统与机器人参数、轨迹规划与连续 IK、控制律、公平外力实验、画作、误差与力矩曲线、视频及三个必答问题。

文字、表格、流程图和轨迹线均是原生 PowerPoint 对象。第 7 页的三张曲线分别展示笔尖三维跟踪误差、受扰相对于正常运行的额外偏移、关节 4 的实际力矩，均为原生图表，内嵌 Excel 数据，可右键“编辑数据”。20 秒、22 秒的虚线标出第一次施力的起止；图内只保留标题、坐标与曲线图例，数值指标放在图外表格中。轨迹线可通过“编辑顶点”修改。真实 Isaac Sim 视口截图为图片，可选中后替换。每页的补充讲解和数据来源都放在备注中，亦保存在 `speaker_notes.md`。

第 8 页放四种控制器的正常绘画视频，第 9 页放对应的外力干扰视频。进入这两页时，该页四个视频会以零延迟同时自动开始播放，方便在同一时刻比较机械臂的动作，无须逐个点击启动。播放过程中仍可点击各个视频画面，单独暂停或继续。八个完整 MP4 已直接嵌入 PPT 文件，复制或移动 PPT 后仍可使用，无须一同携带视频文件或保持文件夹相对位置。每个视频下面都有控制器名称和两行通俗解释，均为可编辑文本框。内嵌视频总量约 360 MiB，因此 PPT 文件会比原来的链接版大。

`raa-v0.pdf` 和 `preview/` 是静态预览，视频位置只显示封面画面；视频在 PPT 的幻灯片放映中播放。视频使用原始 Isaac Sim 三维视口录制，没有重新仿真或改动视频内容。

重新生成 PPT（需要现有的 `python-pptx`，不启动仿真）：

```bash
python3 Pro1/build_ppt.py
```

修改了 `raa-v0.pptx` 后，不要重新生成并覆盖手动修改。字体使用本机已有的 Noto Sans CJK SC；在其他电脑上可在 PowerPoint 中替换成微软雅黑等中文字体。

仅更新现有 PPT 的四路自动播放设置，保留你对文字、排版和其他页面的修改：

```bash
python3 Pro1/build_ppt.py --sync-videos
```

此命令只修改第 8、9 页视频的并行零延迟启动设置，不重建 PPT，也不重新编码视频。`video_playback_verification.json` 保存两页的播放条件与内嵌视频完整性核验结果。

`presentation_sources.json` 保存使用的数据、数值口径和原始文件 SHA256。报告的整体偏差是落笔阶段三维均方根误差（RMSE），不是平面误差或误差的算术平均。恢复时间依据受扰轨迹相对于同一时刻无干扰轨迹的位置差，判定标准是连续至少 0.5 秒处于 2 mm 内。

本次保留真实实验设置：Isaac Sim / PhysX、PD / 重力补偿 PD / RBF / 模糊四种控制器、约 3 N 的三次外力。轨迹使用累计弧长五次时间规划和三次 Hermite 关节插值。附件任务 3 中的计算力矩控制、本次未使用的加速度前馈、50 N 场景和模型失配实验均未运行；PPT 将计算力矩列为原理对照，将模型失配列为后续验证，未把附件的参考数值当作项目实测结果。

`assignment_diagnostics.json` 保存从已有原始记录计算的 IK 残差、相邻关节变化、峰值、恢复时间及力矩曲线数据。`assignment_diagnostics.py` 是离线核对程序，需要已有 NumPy 环境与本机 Isaac 模型路径，不启动仿真。此次仅修改汇报和增加离线诊断文件，控制器与原始实验记录未修改。另提供符合附件命名要求的 `2453703_肖淇文_作业1.pptx` 与同名 PDF，内容与本次 `raa-v0` 文件相同；之后重新生成默认版本或手动编辑后，可用新的文件替换提交版。

`preview/` 保存逐页 PNG 与总览图；PPT 和 PDF 已逐页检查。实验运行源码、控制配置、原始轨迹和视频均保持原样。
